# Folio - Jira 에픽/스토리/태스크 구조

## 에픽 → 스토리 → 태스크 계층 설명

| 계층 | 역할 | 예시 |
|------|------|------|
| **에픽(Epic)** | 기능 도메인 단위. 하나의 큰 기능 영역 | 인증, 원고, 복선 |
| **스토리(Story)** | 사용자 관점의 기능 단위. "~할 수 있다" | 소셜 로그인을 할 수 있다 |
| **태스크(Task)** | 개발 작업 단위. 구현/설계/테스트 | API 개발, UI 구현, DB 마이그레이션 |

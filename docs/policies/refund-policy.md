# 폴리오(Folio) 결제 및 환불 정책

**버전**: v1 (시행일: 2026-05-09)

본 결제 및 환불 정책은 폴리오(Folio, 이하 "회사")가 제공하는 유료 서비스의 결제, 청약철회, 환불에 관한 사항을 규정합니다. 본 정책은 회사의 **이용약관** 및 관련 법령(전자상거래 등에서의 소비자보호에 관한 법률, 약관의 규제에 관한 법률 등)에 근거합니다.

> **결제 시 본 약관 동의 필수.** 결제 화면에서 "환불 규정에 동의합니다" 체크 없이는 결제가 진행되지 않습니다. 동의 시각과 약관 버전은 결제 레코드(`payment.refund_policy_version`, `payment.refund_policy_agreed_at`)에 영구 보관됩니다.

---

## 제1조 (유료 서비스의 종류)

회사는 다음의 유료 서비스를 제공합니다.

1. 종량제 크레딧 (단건 결제): 결제 금액에 따라 크레딧을 지급받아 유료 기능을 이용
2. 구독 플랜 (월 정액): 매월 정액을 지불하고 매월 일정 크레딧을 지급받아 이용

구체적인 결제 상품, 가격, 지급 크레딧 및 기능별 차감량은 회사가 정한 정책에 따르며, 서비스 내 "크레딧 정책" 페이지 또는 별도 고지를 통해 확인할 수 있습니다.

---

## 제2조 (결제 수단)

회원은 회사가 제공하는 결제 수단을 통해 유료 서비스를 이용할 수 있습니다. 결제는 회사가 지정한 결제대행사(PG사) 및 결제 수단 제공자를 통해 안전하게 처리되며, 구체적인 결제 수단의 종류는 서비스 내 안내를 통해 확인할 수 있습니다.

---

## 제3조 (청약철회)

### 1. 청약철회 가능 기간

회원은 「전자상거래 등에서의 소비자보호에 관한 법률」 제17조에 따라 결제일로부터 **7일 이내**에 청약철회를 요청할 수 있습니다.

### 2. 청약철회가 제한되는 경우

다음의 경우 청약철회가 제한되거나 불가합니다.

1. 크레딧을 **일부라도 사용한 경우** (단, 미사용 크레딧은 환불 가능)
2. 구독 서비스의 경우 **구독 기간 일부 이용 이후**
3. 디지털 콘텐츠의 특성상 제공이 개시된 후 회원의 귀책사유로 제공이 완료된 경우

---

## 제4조 (환불 기준)

### 1. 크레딧 충전 (종량제)

| 상황 | 환불 가능 여부 | 처리 |
| --- | --- | --- |
| 결제 후 7일 이내, 미사용 | 가능 | 결제 금액 전액 현금 환불 |
| 결제 후 7일 이내, 일부 사용 | **불가** (회사 귀책 제외) | - |
| 결제 후 7일 경과 | 불가 | - |
| 결제 후 크레딧 만료 | 불가 | - |
| 회사 귀책 (서비스 장애 등) | 가능 | **결제 시 받은 크레딧 전액을 다시 보너스로 지급** (현금 환불 없음) |

**계산 예시 (회사 귀책 보상):**
5,000원에 550 크레딧 구매 후 100 크레딧 사용, 회사 귀책으로 환불 신청 시
→ 현금 환불 없음
→ 보상 크레딧: **550 크레딧을 보너스로 다시 지급** (사용한 100 크레딧 만회 + 잔여 450 보전)

### 2. 구독 플랜

| 상황 | 환불 가능 여부 | 처리 |
| --- | --- | --- |
| 구독 시작 후 7일 이내, 구독 크레딧 **미사용** | 가능 | 구독료 전액 현금 환불 |
| 구독 시작 후 7일 이내, 구독 크레딧 일부 사용 | **불가** (회사 귀책 제외) | - |
| 구독 시작 후 7일 경과 | 불가 | 차월부터 구독 해지로 안내 |
| 회사 귀책 | 가능 | 구독료 전액 현금 환불 |

### 3. 구독 크레딧의 환불 제한

구독 플랜으로 매월 지급된 **구독 크레딧은 매월 말일에 자동 소멸**되며, 소멸된 크레딧은 환불되지 않습니다. 구독 해지 시에도 잔여 구독 크레딧은 해당 월 말일에 소멸되며, 별도 환불 대상이 아닙니다.

### 4. 회사의 귀책사유로 인한 환불

서비스 장애, 시스템 오류, 회사의 귀책사유로 인해 서비스가 정상적으로 제공되지 않은 경우:

- **종량제**: 결제 시 받은 크레딧 **전액을 보너스 크레딧으로 다시 지급** (현금 환불 없음). 사용 기록과 무관하게 보상.
- **구독**: 결제 금액을 **전액 현금 환불**.

회사 귀책 환불은 7일 경과 후에도 신청 가능하며, 회사 검토를 거쳐 처리됩니다.

---

## 제5조 (환불 요청 방법)

### 1. 요청 절차 — 이메일 기반 검토

환불은 사용자가 신청한다고 즉시 처리되지 않으며, **회사 검토 후 승인된 경우에만** 환불됩니다.

1. 회원은 **서비스 내 "결제/구독" 화면 → 결제 이력 → "환불 신청"** 으로 신청합니다.
2. 신청 시 다음을 입력합니다:
    - 환불 사유 (단순 변심 / 서비스 불만 / 결제 오류 / 회사 귀책 / 기타)
    - 자유 사유 (선택, 500자 이내)
3. 회사 운영자({@code 2square.f203@gmail.com})에게 자동으로 이메일이 발송됩니다.
4. 회사는 요청 접수 후 **3영업일 이내**에 정책 검토하여 승인/거절을 결정합니다.
5. 승인 시 결제수단과 동일한 방법으로 환불 처리, 거절 시 사용자에게 사유 안내.

### 2. 재신청

거절된 경우 **1회까지 재신청** 가능합니다. 회사 검토 결과를 받은 뒤 추가 정보를 보강하여 재신청할 수 있습니다.

### 3. 환불 처리 기간

- 환불 승인 후 **3~10영업일 이내** 환불 처리
- 결제 수단 및 금융기관 사정에 따라 환불 기간이 달라질 수 있습니다.

### 4. 환불 방법

- **결제 수단과 동일한 방법**으로 환불됩니다.
- 카카오페이로 결제한 경우: 카카오페이로 환불
- 회사 귀책 종량제 환불은 **현금이 아닌 크레딧 보상**으로 처리됩니다 (제4조 4항).
- 환불 시 별도의 수수료는 발생하지 않습니다.

## 제6조 (환불이 제한되는 경우)

다음의 경우 환불이 제한될 수 있습니다.

1. 회원의 약관 위반, 부정 이용으로 인한 계약 해지
2. 크레딧을 모두 사용한 후 환불 요청
3. 회원이 제공한 정보가 허위인 경우
4. 관련 법령에서 환불을 제한하는 경우

## 제7조 (크레딧의 유효기간)

크레딧은 종류에 따라 다음과 같은 유효기간을 가집니다.

| 크레딧 종류 | 유효기간 |
| --- | --- |
| 종량제 크레딧 (단건 결제) | 구매일로부터 **5년** |
| 구독 크레딧 (매월 지급) | 지급일이 속한 달의 **말일까지** (이월 불가) |
| 무료 지급 크레딧 (신규 가입 등) | 지급일로부터 **5년** (별도 안내가 있는 경우 해당 기간) |

- 유효기간 경과 시 크레딧은 자동 소멸되며, 환불되지 않습니다.
- **구독 크레딧은 매월 말일에 잔여분이 자동 소멸되며, 다음 달로 이월되지 않습니다.**
- 회원이 유료 기능을 이용할 때 크레딧은 **구독 크레딧 → 종량제 크레딧** 순서로 차감됩니다.
- 회원 탈퇴 시 잔여 크레딧은 모두 소멸되며, 탈퇴 전 환불 정책에 따른 환불만 가능합니다.

## 제8조 (구독 해지)

### 1. 해지 방법

구독 플랜은 서비스 내 **"설정 > 구독 관리"** 에서 언제든지 해지할 수 있습니다.

### 2. 해지 효과

- 해지 요청 시 **다음 결제일부터 구독이 종료**됩니다.
- 이미 결제한 당월 구독은 해지일과 관계없이 **해당 월 말까지 이용 가능**합니다.
- **잔여 구독 크레딧은 해당 월 말일에 소멸되며, 다음 달로 이월되지 않습니다.**
- 해지 후에도 **종량제 크레딧 및 무료 지급 크레딧**은 각자의 유효기간 내에서 사용할 수 있습니다.

### 3. 자동 갱신

구독 플랜은 해지하지 않는 한 매월 자동으로 갱신되며, 결제일에 등록된 결제 수단으로 자동 결제됩니다.

---

## 제9조 (회사의 폐업·서비스 종료 시 처리)

1. 회사는 영업상 사정으로 서비스를 종료할 수 있으며, 종료 30일 전 회원에게 사전 공지합니다.
2. 서비스 종료 시 회원의 미사용 크레딧은 다음과 같이 처리됩니다.
    - **종량제 크레딧**: 잔여 크레딧을 결제 금액 비례로 환불
    - **구독 크레딧**: 당월 잔여 일수 비례 환불
3. 회사가 폐업·파산·해산하는 경우, 환불은 회사 자산 한도 내에서 이행됩니다. 자산 부족 시 회원은 일반 채권자로서 파산 절차를 통해 청구할 수 있습니다.
4. 천재지변, 전쟁, 정부 명령 등 불가항력으로 인한 서비스 중단 시 회사는 책임을 지지 않습니다.

2. 협의가 이루어지지 않을 경우, 공정거래위원회 또는 소비자분쟁조정위원회에 조정을 신청할 수 있습니다.
3. 법적 분쟁 발생 시 대한민국 법령이 적용되며, 관할 법원은 민사소송법에 따른 관할 법원으로 합니다.

1. 본 환불 정책에 명시되지 않은 사항은 이용약관, 관련 법령, 사회 통념을 따릅니다.
2. 회사는 필요에 따라 본 정책을 변경할 수 있으며, 변경 시 시행일 7일 이전에 공지합니다.
3. 회원에게 불리한 변경의 경우 30일 이전에 공지하며, 개별 고지합니다.

## 부록 — 코드 구현 매핑 (개발자용)

본 약관 조항이 어디에 구현되어 있는지 추적용. 약관 변경 시 동기화 체크리스트.

| 약관 조항 | 구현 위치 |
| --- | --- |
| 약관 버전 (v1) | `RefundPolicy.CURRENT_VERSION` |
| 결제 시 동의 강제 | `CreatePaymentRequest.agreeRefundPolicy` (`@AssertTrue`) + `CreateSubscriptionRequest` 동일 |
| 동의 시점·버전 보존 | `Payment.refundPolicyVersion`, `Payment.refundPolicyAgreedAt` (NOT NULL) |
| 제3조 1항 (7일 청약철회) | `RefundService.WITHDRAWAL_DAYS = 7` |
| 제4조 1항 (종량제 미사용 전액 / 일부 사용 차단) | `RefundService.calcOnetimeRequest()` — 잔액으로 사용 여부 판단, 단순 변심 일부 사용 차단 |
| 제4조 2항 (구독 미사용 전액 / 일부 사용 차단) | `RefundService.calcSubscriptionRequest()` — `subscriptionBalance < granted` 차단 |
| 제4조 3항 (구독 크레딧 월말 소멸) | **미구현** — 현재는 다음 갱신 시점 EXPIRE. Phase B에서 월말 스케줄러 추가 검토 |
| 제4조 4항 (회사 귀책) | `RefundService.calcCompanyFault()` — 종량제 `COMPANY_FAULT_CREDIT` (크레딧 보상) / 구독 `FULL` (현금) |
| 제5조 1항 (이메일 기반 검토) | `RefundService.requestRefund()` → `EmailNotifier.notifyOperator()` |
| 제5조 2항 (재신청 1회) | `RefundService.MAX_REJECTED_RETRIES = 1` + `RefundRepository.countByPayment_IdAndStatus` |
| 제5조 (운영자 승인) | `RefundService.approveRefund()` / `rejectRefund()` — 현재 관리자 API 미구현, DB 직접 수정 필요 |
| 제6조 (환불 제한) | `calcOnetimeRequest()` / `calcSubscriptionRequest()` — REFUND_REQUEST_DENIED |
| 제7조 (종량제 5년 유효기간) | **미구현** — Phase B에서 도메인 + 만료 스케줄러 추가 |
| 제7조 (구독 크레딧 월말 소멸) | 위 제4조 3항과 동일 — Phase B |
| 제8조 (구독 해지) | `SubscriptionService.cancel()` |

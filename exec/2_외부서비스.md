# 2. 외부 서비스 가입 및 활용 정보

본 프로젝트에서 사용하는 모든 외부 서비스의 가입 절차, 콘솔 위치, 발급 키, 환경변수 매핑을 정리한다.

---

## 1. Google OAuth 2.0 (소셜 인증)

데스크탑(Electron) / 웹 에디터 / 백엔드 모두 Google OAuth 2.0 으로 인증한다.

| 항목 | 내용 |
|------|------|
| 콘솔 | https://console.cloud.google.com/apis/credentials |
| 프로젝트명 | `storyzip` (또는 팀 GCP 프로젝트) |
| 인증 유형 | OAuth 2.0 Client ID (Web application) |
| Authorized JavaScript Origins | `http://localhost:5173`, `https://<배포도메인>` |
| Authorized Redirect URI | `http://localhost:8080/login/oauth2/code/google`, `https://<배포도메인>/api/login/oauth2/code/google` |
| 동의 화면 | External, 스코프: `openid`, `profile`, `email` |

### 발급 후 환경변수 매핑

| Doppler 키 | 사용처 |
|-----------|--------|
| `GOOGLE_CLIENT_ID` | Backend (`application.yml`) |
| `GOOGLE_CLIENT_SECRET` | Backend |
| `VITE_GOOGLE_CLIENT_ID` | Frontend (브라우저 OAuth flow) |

> Electron 앱은 시스템 브라우저를 열어 Google 로그인 → 인증 완료 후 커스텀 프로토콜(`folio://oauth-callback`)로 앱에 콜백한다.

## 2. Anthropic Claude API (LLM)

AI 서버에서 원고 첨삭/요약/캐릭터 생성 등 LLM 기능에 사용한다.

| 항목 | 내용 |
|------|------|
| 콘솔 | https://console.anthropic.com |
| 발급 항목 | API Key (`sk-ant-...`) |
| 사용 모델 | `claude-sonnet-4-5`, `claude-haiku-4-5-20251001` |
| 결제 | Pay-as-you-go (입력/출력 토큰 단가 기준) |

### 환경변수 매핑

| Doppler 키 | 사용처 |
|-----------|--------|
| `ANTHROPIC_API_KEY` | AI 서버 (`ai/app/llm/anthropic_client.py`) |
| `CLAUDE_SONNET_MODEL` | 기본 모델 ID |
| `CLAUDE_HAIKU_MODEL` | 경량 모델 ID |
| `LLM_PROVIDER` | `anthropic` (prd) / `fake` (테스트) |

> 로컬 테스트 시 `LLM_PROVIDER=fake` 로 두면 더미 응답이 반환되어 API 키 없이 동작한다.

## 3. OpenAI Embedding API

문서 검색 / 유사 캐릭터 추천 등 임베딩에 사용. (Claude는 임베딩 미지원)

| 항목 | 내용 |
|------|------|
| 콘솔 | https://platform.openai.com/api-keys |
| 발급 항목 | API Key (`sk-...`) |
| 사용 모델 | `text-embedding-3-small` (1536 dim) |

### 환경변수 매핑

| Doppler 키 | 사용처 |
|-----------|--------|
| `OPENAI_API_KEY` | AI 서버 |
| `EMBEDDING_MODEL` | `text-embedding-3-small` |
| `EMBEDDING_PROVIDER` | `openai` (prd) / `fake` (테스트) |

> SSAFY GMS 키 발급 전에는 `EMBEDDING_PROVIDER=fake` 로 두고 더미 벡터 사용.

## 4. PowerSync (Electron ↔ Server 동기화)

| 항목 | 내용 |
|------|------|
| 콘솔 | self-hosted (`journeyapps/powersync-service` 컨테이너) |
| 라이선스 | Open source (self-hosted 무료) |
| 의존성 | PostgreSQL (logical WAL) + MongoDB (replica set, bucket storage) |
| 클라이언트 SDK | `@powersync/web`, `@powersync/react-native` 등 |

### 환경변수 매핑

| 변수 | 사용처 |
|------|--------|
| `VITE_POWERSYNC_URL` | Frontend (`https://<domain>/sync`) |
| PostgreSQL `wal_level=logical` | PowerSync replication 전제 |
| Mongo replica set | bucket storage |

> 자세한 동작은 [docs/powersync.md](../docs/powersync.md) 참고.

## 5. Google Analytics 4 (GA4)

| Doppler 키 | 사용처 |

| `GA4_DEBUG_ENDPOINT` | `https://www.google-analytics.com/debug/mp/collect` |

상세: [docs/ga4-reporting-plan.md](../docs/ga4-reporting-plan.md), [docs/ga4-offline-analytics-plan.md](../docs/ga4-offline-analytics-plan.md)

## 10. Let's Encrypt (SSL)

| 항목 | 내용 |
|------|------|
| 발급 도구 | Certbot (컨테이너) |
| 도메인 검증 | HTTP-01 (`/.well-known/acme-challenge/`) |
| 갱신 주기 | 12시간마다 자동 (`certbot renew`) |
| 인증서 경로 | `/opt/folio/data/certbot/conf/live/<domain>/` |

별도 가입 불필요. EC2에 도메인이 연결되어 있어야 발급 가능.
